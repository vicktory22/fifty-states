# Fifty States

Guess the 50 U.S. states from Census-derived outlines. Built with TanStack Start and TanStack Store.

- Map geometry: [us-atlas](https://github.com/topojson/us-atlas) `states-10m` (U.S. Census cartographic boundaries), Albers USA projection with Alaska/Hawaii insets.
- UI chrome: [ThreeUI](https://www.threeui.com) community components (`PredictiveArcCanvas`, `SparkBadge`, `DiagnosticsPanel`).

```bash
pnpm install
pnpm dev
pnpm test
```
